# WP11 auto-math

## Summary
Automatic math mode (feature 2) works in the editor, in Source and Visual
mode. When a word ends (a space, `, . ; : ! ?` or a closing `) ] }`), a math
word in text or a table cell becomes inline math: `where x_i is ` gives
`where $x_i$ is `, `p < .05,` gives `$p < .05$,`, `x^10 ` gives `$x^{10}$ `,
`x_max` gives `$x_{max}$`, `\frac{1}{2},` gives `$\frac{1}{2}$,`, and
`x_1 + y_2 ` gives `$x_1 + y_2$ `. A name that is not math gets `\_`
(`my_var` gives `my\_var`; `\texttt{x_1}` gives `\texttt{x\_1}`). The file's
dominant delimiter is used (`\(…\)` when the file uses it more). Each change
is one undo step, Backspace right after puts back what was typed, and that
spot never fires again. Tab right before a closing `$` or `\)` leaves the
formula. Inside math the completion list ranks math commands first and lists
each label once. Every behaviour has a switch in Settings → Math.

## Deviations
- **Settings** (all account scope, section `math`):
  - `automath.wrap` (switch, automatic, palette, default on): T1, T2, T3 and T5.
  - `automath.identifiers` (switch, automatic, default on): the `\_` rule. Its own switch, because escaping names and wrapping math are different wishes.
  - `automath.delimiter` (`'auto' | 'dollar' | 'paren'`, default `'auto'` = `inlineMathStyle`), dependsOn `automath.wrap`.
  - `automath.tabOut` (switch, automatic, default on): Tab at priority 70 (`KEY_CHAIN_PRIORITY.Tab.mathTabOut`), after completion, fields, suggestions and WP12's closer step-out.
- **Two rules**, both priority 40: `automath.wrap` (setting `automath.wrap`) and `automath.identifier` (setting `automath.identifiers`). They share one pure classifier (`planFor`), so a math-looking word is never escaped when wrapping is off, and a declined wrap does not fall back to an escape.
- **T5 (merge)** only extends a formula automatic math mode wrote in the current run of typing (the `freshFormula` field: cleared by a caret move, a change inside the formula, or leaving the line), never one the person typed. The gap may hold only operators, numbers, single letters and spaces, with at least one operator. This also makes `x_i = 5,` come out as `$x_i = 5$,` (the `x_i` is wrapped first, then merged).
- **Decimal points:** a `.` right after a number with no `.` yet does not end a T3 relation (`p < 0.` waits for `05`); a `,` does (`n = 1,000` becomes `$n = 1$,000`; Backspace undoes it).
- **A relation command on its own right after a word** (`x \le `) waits for its right-hand side instead of becoming `$\le$`.
- **Not built (listed under Remaining):** T4 (Unicode symbols under pdfLaTeX), and the report's eager wrap when a math-only completion is accepted in text. Display math is never inserted (the plan defers it). `$` pairing and the currency guard are WP12's.

## Remaining
- **T4:** under pdfLaTeX, `α ` → `$\alpha$ ` and `x ≤ 5 ` → `$x \le 5$ ` for Unicode symbols outside `PDF_TEXT_OK` (`visual/context.ts` `pasteNeedsSymbols()`, `UNICODE_MATH`). Today a `≤ ≥ ≠` typed as a T3 relation is already converted; a lone Unicode symbol is not.
- **Eager wrap on completion:** accepting a math-only completion in text (`\frac` → `$\frac{¦}{}$`) through the completion filter's `apply`. Typing `\frac{1}{2},` already wraps lazily.
- **Project macros** are read from the open file's first 60 KB only (`\newcommand` with a math body, `\DeclareMathOperator`), not from other files of the project.

## For later packages
- **WP38 (statistics):** `import { autoMathFormatters } from '../automath/api'` and provide `autoMathFormatters.of({ id, format(i) { … } })` in your editor extension. `i.text` is the line up to the boundary character at `i.at`, `i.open`/`i.close` are the file's delimiters; return `{ from, to, insert }` with `i.lineFrom <= from <= to <= i.at`, or null. It runs before automatic math mode's own rules in text (not in monospace text), and the result is an ordinary `automath.wrap` edit (one undo step, Backspace reverts, declined spots respected, setting `automath.wrap`). Your own transactions carry `statsEdit`, so the core never runs these rules on them.
- **Rule names** for `declined()` and `autoEditMark`: `AUTO_MATH_RULES.wrap` (`'automath.wrap'`) and `.identifier` (`'automath.identifier'`).
- **WP10 (escape):** `_` belongs to this package; WP10 handles `& % #`.
- **WP12 (pairs):** Tab-out sits at 70, below your closer step-out at 72, and moves past `$`, `$$`, `\)` and `\]` only when the caret is in that formula.
