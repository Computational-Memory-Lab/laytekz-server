# WP10 escape-typing

## Summary
Feature 1 works in the editor. In a .tex file, `&` typed in text becomes `\&`.
It stays raw at the top level of a table cell and in math. `%` becomes `\%`
only straight after a number (`50%`, `3.5%`, `12\,%`); anywhere else it starts
a comment. `#` becomes `\#` in text, tables and math, and stays raw in
definitions, URLs and code. Pasting plain prose in Source mode escapes it the
way Visual mode already does (in a table cell `&` stays raw). ⌘⇧V
(Ctrl+Shift+V) pastes exactly as copied in both modes. A chip beside the file
name shows the typing context at the cursor. Each automatic edit is its own
undo step, Backspace right after reverts it, and its notice shows at most 3
times. Each part has its own switch in Settings › Typing.

## Deviations
- **Settings** (account scope, all default on, section `typing`):
  - `escape.amp` "Escape & in text" (automatic, palette)
  - `escape.percent` "Escape % after a number" (automatic, palette)
  - `escape.hash` "Escape # in text" (automatic)
  - `escape.paste` "Escape pasted text" (automatic)
  - `escape.chip` "Show the typing context" (not automatic: it never changes text)

  Each rule's `settingId` is its own switch, so the core's `autoEditSettings`
  turns it off. There is no master switch: per-character switches were enough
  for the plan's "on, per character".
- **⌘⇧V is a fixed binding** (`escape.pasteRaw`, scope `editor`,
  `changeable: false`, group "Editor"), and no command is registered under that
  id. The paste event comes from the browser's own plain-text paste chord, so
  rebinding it to another chord could never make a paste. If a command existed,
  WP05's editor dispatcher would return true, which calls `preventDefault` and
  stops the browser's paste. A `domEventObservers` keydown notes the chord
  (`matchesShortcut`), and the next non-empty paste within 1 s is inserted as
  copied.
- **An escaped paste takes two steps.** The text first lands as copied
  (`input.paste`), then `applyExplicitEdit` replaces it with the escaped text,
  marked `autoEditMark('escape.paste')`. One ⌘Z or Backspace leaves the text
  exactly as copied, and a second ⌘Z removes the paste.
- **Paste escaping runs only in Source mode.** Visual mode keeps its own
  `pasteLatex`, which already escapes prose. Pasting in math, comment,
  verbatim, literal or code contexts, pasting the editor's own copies
  (`isOwnCopy`), and pasting text where `looksLikeLatex` is true all leave the
  text as copied. In a table cell `&` is swapped for a private-use placeholder
  around `pasteText`, so the escaper itself is reused and not copied.
- **Chip labels:** `Text`, `Text in math`, `Table · cell N`, `Math`,
  `Math · <env>`, `Comment`, `Verbatim`, `Literal · <detail>`, `Preamble`,
  `Definition`, `Code · <detail>`. The tooltip says what typing does there.
  Clicking the chip opens Settings › Typing. `data-testid="typing-mode"`, and
  `data-kind` holds the context kind. It shows only while a .tex/.ltx file is
  open (the feature's compartment exists only there).
