# WP08 typing-core

## Summary
The shared LaTeX context (`editor/texContext`), the LaTeX vocabulary twin
(`latex/vocab.ts` on both sides), the automatic-edit core
(`editor/core/autoEdit.ts`), its notices (`editor/core/notices.ts`) and a
headless replay harness now exist. `contextAt` tells text, table cell, math,
comment, verbatim, literal and code apart with every grammar workaround of
the editor-typing report; `formulaAt`/`formulasIn`, `tableEnvAt`,
`commandAt`, `inlineMathStyle` and `documentPackages` serve features 1–4,
12, 17 and 18. The core runs feature rules after a keystroke and makes each
result one undo step that Backspace reverts. Nothing changes for a user in
wave 0: no feature provides a rule yet, and the editor host installs the
core only when one does.

## Requests

### R1: apps/web/src/editor/core/featureHost.ts (WP05): route automatic-edit notices to the page's toast
- **Anchor:** inside `private autoEditExtension(rules: readonly AutoEditRule[]): Extension`, the line
  `      return autoEditCore(rules);`
- **Hunk** (replaces that line; plus one import beside `import { autoEditCore } from './autoEdit';`):
  ```diff
  +import { autoEditNotices } from './notices';
  …
  -      return autoEditCore(rules);
  +      // Galley: V2 (WP08) a rule's notice and the "turn it off?" offer go to the page's toast.
  +      return [autoEditCore(rules), autoEditNotices.of((text, kind, action) => this.o.ctx.notify(text, kind, action))];
  ```
- **Why:** `autoEditCore(rules)` (frozen signature) has no notify parameter; notices reach the user through the `autoEditNotices` facet, which only the editor host can provide with the page's `notify`.
- **Without it:** automatic edits work (edit, undo step, Backspace revert, flash); their notices and the offer to turn a rule off are silently dropped.

## Deviations
No frozen signature changed. Additions and decisions where the contract left room:

- **Extra exports.**
  - `texContext/index.ts`: `extraTableEnvironments: Facet<readonly string[], ReadonlySet<string>>`, more `tabular`-family environment names (a feature's settings list); the report's "user's list from settings".
  - `core/autoEdit.ts`: `autoEditMark: AnnotationType<string>` (an edit carrying it is revertible by Backspace; the core's follow-ups carry `AutoEdit.rule`, a command may add it to its `applyExplicitEdit` spec); `autoEditSettings: Facet<(settingId) => boolean>` (default: `getSetting(id) !== false`, a throwing store counts as on); `typedInputOf(tr)`, `planAutoEdit(tr)`, `applyPlannedAutoEdit(view, plan)`, `revertAutoEdit(view)`, types `PlannedAutoEdit`, `AutoEditView`.
  - `core/notices.ts` (new file, named by the plan): `autoEditNotices` facet, `NoticeSink`, `NoticeAction`, `NOTICE_LIMIT = 3`, `REVERTS_BEFORE_OFFER = 2`, `NOTICE_COUNTS_KEY`, `showAutoEditNotice`, `noteAutoEditRevert`, `resetAutoEditNotices`.
- **Command names have no backslash** everywhere (`TexContext.arg.command`, `CommandSpan.name`, the vocabulary), matching D11's `citeCommandFor` (`'cite'`). A `*` written right after the name is kept (`'section*'`, `'citep*'`). An environment's name group and its `\begin` arguments report `command: 'begin'` (or `'end'`); `\\[2pt]` is the command `'\'`.
- **Argument spans are contents.** `TexContext.arg.from/to` and `CommandSpan.args[i].from/to` bound what is between the delimiters (an unclosed argument runs to the end of what the parser gave it). `CommandSpan.from` is the backslash, `to` the end of the last argument. `arg.index` counts optional and mandatory arguments together.
- **ArgKind where the union has no exact word:** a value a package reads (`\SI`, `\ce`, glossary keys) is `kind: 'literal'` with `arg.kind: 'option'`; `\verb`/`\lstinline` content and math arguments (`\frac{…}`) have `arg: null`.
- **`TexContext.math`:** `delim`/`display` say how math was entered (the outermost math construct of the formula); `env` is set only when `delim === 'env'` and names that environment; the innermost math environment is `detail` (`'pmatrix'`) and `ctx.env`.
- **`detail` strings:** text `''` or `'text in math'`; math the innermost math environment or `'inline'`/`'display'`; table `'cell N'`; verbatim the environment or command; literal `'URL'`, `'email'`, `'path'`, `'citation key'`, `'reference key'`, `'label'`, `'package'`, `'class'`, `'environment name'`, `'color'`, `'units'`, `'chemistry'`, `'glossary key'`, `'value'`; code `'preamble'`, `'definition'`, `'option'`, `'after document'` or the environment (`'tikzpicture'`); comment `''`.
- **Precedence:** comments (from the line) win; then any literal, verbatim or code layer anywhere around the position (the innermost one names it), so math inside a definition or tikzpicture is code and a `\label` in math is literal; then math (text inside `\text{}` etc. is `'text in math'`); then a table's top level; then the preamble; then text.
- **Preamble** exists only in a file with an uncommented `\documentclass` in its first 20 KB; a file without one (a chapter) is all document body.
- **`formulaAt`:** with no `side` in the contract, a formula holding `pos` strictly wins, then one ending at `pos`, then one starting there; a hover passes `pos + 1` to ask about the character after `pos`. `tikzcd` is math to `contextAt` but not a formula. `tableEnvAt` returns the innermost table environment whose whole span (`\begin` to `\end`) holds `pos`; `bodyFrom` follows the vocabulary's argument signature when it has one.
- **`declined(state, pos, rule)`** is keyed by `AutoEdit.rule` (the rule's id when empty), and the core skips a rule result whose changes touch a declined spot of the same rule. A declined spot covers the reverted range and the caret; it does not grow when text is typed at its ends.
- **Additions to the core the plan implies:** a one-shot flash (`cm-auto-edit` mark, `EditorView.baseTheme`, colour `var(--auto-edit-flash, rgba(234, 179, 8, 0.35))`, off under `[data-motion="reduce"]` and `prefers-reduced-motion`), and the report's "after two reverts in a session, offer to turn the rule off" (once per rule per tab, also capped at 3 per browser, gated by `typing.explain`).
- **Unknown table environments:** besides the vocabulary, the facet and the preamble's `\newenvironment`/`\NewDocumentEnvironment` wrappers, a name matching `/tab(?!le)|tbl/i` that the vocabulary does not know is a tabular (`mytabular` yes, `mytable` no: floats are named like that).

## For later packages
- **A rule** is pure: read `t.before` (the tree before the keystroke), return positions in `t.after`.
  ```ts
  const amp: AutoEditRule = { id: 'escape.amp', priority: AUTO_EDIT_PRIORITY.escape, settingId: 'escape.amp',
    run: (t) => t.char === '&' && contextAt(t.before, t.from)?.kind === 'text' ? { rule: 'escape.amp', changes: { from: t.from, insert: '\\' }, notice: { kind: 'escape.amp', text: 'Typed & became \\&. Backspace undoes it.', settingId: 'escape.amp' } } : null };
  export const module: FeatureModule = { id: 'escape', editor: { autoEditRules: [amp] } };
  ```
  `contextAt` returns null when the tree is not ready: do nothing then. A rule that checks an odd backslash run before `t.from` itself stays correct after `\`.
- **Commands** that edit on their own use `applyExplicitEdit(view, spec)` (one undo step); add `annotations: autoEditMark.of('<rule>')` to make Backspace right after revert it, and include `autoEditCore([])` in the feature's extension so the machinery is present (it is one shared instance, installed once).
- **The statistics fields (WP38)** annotate their transactions with `statsEdit.of(true)` and re-export `statsEdit`.
- **Tables (WP14):** `tableEnvAt` and `TABLE_ENVIRONMENTS`/`TABLE_ENVIRONMENT_ARGS` are the families and signatures; `extraTableEnvironments.of(names)` adds a settings list.
- **Math hover (WP13):** `formulaAt(state, pos + 1)` for the character under the pointer; `formulasIn` for a viewport.
- **Tests:** `editor/core/__tests__/replay.ts` exports `headlessView(config, plugins?)`, `typeChar`, `typeText`, `pressKey` (runs the key chains, then Backspace/Enter defaults), `settle`, `withCaret` and `replay(source, extensions)` → `{ keystrokes, autoEdits, divergences, doc, identical }`, the measure for the integration replay gate. It runs about 1,800 keystrokes a second with the LaTeX parser on (the demo paper, 5.6 KB, in about 3 s). Mock `settings/store` in unit tests (`getSetting` → undefined means on).
- **The vocabulary** is frozen with this package (only the integrator edits it after wave 0): edit both copies; three checks fail while they differ.
