# WP26 crossref-picker

## Summary
⇧⌘X (Ctrl+Shift+X) opens the cross-reference picker over the editor: the
project's labels (WP15's `GET …/labels?detail=1`), grouped by kind (figures,
tables, equations, sections, appendices, hypotheses and theorems, items,
listings, other) with their caption, heading or equation and `label · file:line`.
Type to filter (every word must match; case and accents ignored), Tab to
reference several, Enter to insert the document's form, Shift+Enter for a bare
`\ref`. The form follows the packages (WP15's `GET …/cite-setup`): with
cleveref `\cref{a,b}` (`\Cref` at a sentence start, and everywhere under the
apa7 class); without it `Figure~\ref{a}`, `Table~\ref{a}`, `Section~\ref{a}`,
`Hypothesis~\ref{a}`, `\eqref{a}` (amsmath) or `(\ref{a})`, bare `\ref` for
items; several labels join APA-style ("Figures~\ref{a}, \ref{b}, and~\ref{c}").
A kind name already typed before the caret ("Figure ", "fig.") is not repeated:
the space becomes a tie (`Figure~\ref{fig:x}`). "Insert label here" (palette,
the editor's app menu, bindable, unbound by default) writes a `\label` named
from the context and placed where it numbers the right thing: after
`\caption{…}` in a float, at the end of the row in an equation, after
`\begin{…}` in a theorem, after `\item` in an enumerate, after the heading of
the section the caret is in. Typing `\label{` offers the same name as a
completion item marked "suggested" (a switch in settings).

## Deviations
- **Labels on the client** come from `crossrefs/labelIndex.ts` (its own stale-while-revalidate cache of `GET …/labels?detail=1`), because `latexExtras.ts`'s label cache is private. Page `docChanged`/`filesChanged` mark it stale; the picker refetches on every open and shows the cached list meanwhile.
- **The setup** comes from the citations feature's cite-setup cache (`citations/api.ts` `cachedSetup`/`loadSetup`); before the server answers, from the open file's preamble (`detectSetupIn`).
- **Groups** are filter buttons (`ref-picker-group-<group>`, shown when there are two or more groups) and a kind word on each row's right; with no query, rows follow group order and then the server's file order. There are no group headings inside the list (PickerShell has no heading rows).
- **The picker's own chord** (⇧⌘X again) moves to the next form; the "More" forms (`\cref`, `\Cref`, `Figure~\ref`, `\ref`, `\autoref`, `page~\pageref`, `\nameref`, `\eqref`, `\vref`) are a row of buttons, each shown only when the document loads its package (or when it is the form chosen in settings).
- **Explicit forms are written as chosen**: only Automatic and `Figure~\ref` leave out a kind name already typed before the caret. Under Automatic with cleveref, a typed "Figure " gives `Figure~\ref{…}` (a `\cref` would print "Figure Figure 1").
- **Tidy spacing off** (`crossrefs.spacing`): no space is added after a word and "Figure " keeps its space; a kind name typed with no space at all still gets a tie (`fig.~\ref`), since `fig.\ref` would print the number glued to the word.
- **"Insert label here" outside floats, equations, theorems and items** labels the section the caret is in, on its heading's line after the `}` (or selects that heading's label when it already has one, also on the next line), with a toast when this is away from the caret. Before any heading it writes `\label{sec:<n>}` at the caret. A float without a caption gets its label at the caret, named from the `\includegraphics` file.
- **The app-menu item** ("Insert label here", group `insert`) does not claim a plain right-click, so it shows whenever the editor's app menu opens (inside a selection, or on another feature's target such as a link), not on a right-click over plain text.
- **The `\label{` suggestion is `automatic: true`** (listed under "Automatic changes", off under `aldine.settings.testDefaults='automatic-off'`), so legacy specs that type labels never see a completion list they did not expect. It is offered only while the argument is empty or a prefix of the suggestion; accepting it adds the closing brace when missing.
- **Not built:** the typeset numbers in rows ("Figure 3 · p. 12" from the `.aux`); a phone-specific layout beyond PickerShell's full-width sheet; Visual mode's chip editing. Find references (⇧⌥↩) and go to definition are WP20's.

## Privacy notes
No new data leaves the browser. The picker reads `GET /api/projects/:id/labels?detail=1` and `GET /api/projects/:id/cite-setup` (WP15), both derived from the project's own files. The four settings are account scope (synced with the account's preferences like every account setting).
