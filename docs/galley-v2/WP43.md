# WP43 suggest-model

## Summary
Feature 12's "tab complete with a simple downloadable language model". A new
row in Settings › Completion, **Smarter suggestions (experimental)**, off by
default. Turning it on downloads Granite 4.0 350M Base (IBM, Apache-2.0,
Q4_K_M GGUF, 237 MB) once from Hugging Face, pinned to a commit. The row shows
a progress bar and a Cancel button. The file streams into Cache Storage, is
checked against its SHA-256, and is deleted if the check fails. After that the
model feeds WP40's grey inline suggestions: at a word boundary in prose,
250 ms after the last typed character, it suggests the next few words, trimmed
by WP40's rules. Tab accepts them as one undo step, as for the word ghost.
The model runs in this browser through wllama (llama.cpp compiled to
WebAssembly, in a worker, with WebGPU where available and the CPU otherwise).
Nothing typed leaves the computer. When the browser cannot run the model (no
WebAssembly SIMD or exception handling, under 2 GB reported memory, no site
storage or secure context, no space, or a blocked download), the row says why,
and the word suggestions keep working. Remove model deletes the stored file.
If the browser evicted it (Safari after 7 days without a visit), the row reads
"The model is not on this device" and offers Download again. Nothing ever
downloads without the switch or that button.

## Deviations
- **Gate replaced by an experimental opt-in**, as the orchestrator directed. The row is always visible, labelled experimental, and off by default. No timing medians, soak, or 300-cut-point comparison were run. The hint says suggestions may be slow on some computers.
- **Cache Storage, not an OPFS worker.** `cache.put` streams a `Response` to disk in Chromium, Firefox and Safari without holding the file in memory, and the hash runs on the chunks as they pass. No pause or resume: Cancel discards the partial download. A reload during the download also discards it, and the row then offers Download again.
- **Device scope.** One browser's switch never starts a download in another.
- **`dependsOn: 'suggest.words'`.** The model feeds WP40's ghost, which exists only while "Inline word suggestions" is on.
- **No palette toggle.** Turning the row on starts a 237 MB download, which belongs on the row with its progress and Cancel.
- **Word-boundary rule** as the report says: the model is asked only after a space or punctuation, before a line end, a space or one of `)]}$.,;:`. Mid-word, the word ghost answers, unless the "Ask for a suggestion" key (⌥\ / Alt+\) is pressed. The prompt leaves out the prefix's trailing space (a lone space token confuses the tokenizer). A continuation must then start with a space, which is removed.
- **Not built:** the battery guard, the 1B option, the "Run on this server" mode, the speed self-test with a "Use anyway" button, and a live-region announcement (WP40 has none either). Phones are not special-cased: the row is off by default everywhere.
- **No COOP/COEP** (the briefing note), so wllama runs single-threaded on the CPU when there is no WebGPU.

## Privacy notes
- The only new outside host is Hugging Face, contacted only when the person turns the row on or presses Download again. The request is `GET https://huggingface.co/ibm-granite/granite-4.0-350m-base-GGUF/resolve/b2628819fb4e3ee4a42988e532483124b3366bd2/granite-4.0-350m-base-Q4_K_M.gguf`, with `credentials: 'omit'` and `referrerPolicy: 'no-referrer'`. It redirects to `https://*.hf.co` (currently `us.aws.cdn.hf.co`). CSP hosts: `https://huggingface.co` and `https://*.hf.co` (WP45 also lists `https://*.huggingface.co`).
- `wllama.wasm` (10 MB) and the runtime chunk are served by this site.
- Stored on the device: Cache Storage `laytekz-suggest-model` (the model) and localStorage `aldine.suggest.model` (the switch). Nothing goes to the account or the server.
- The prompt is at most about 2,000 characters before the caret (never the preamble) and 300 after it. It is used inside the browser's worker and never leaves it.

## For later packages
- A different or larger model needs a new `ModelManifest` in `manifest.ts`: the URL pinned to a commit, the byte size, the SHA-256, and the FIM and stop tokens. Point `MODEL` at it. The Cache Storage key is the URL, so the old file is not reused; call `removeModel` for it.
- `modelManager()` is per tab. `runtime(signal)` never downloads. `download()` is called only from the settings control.
