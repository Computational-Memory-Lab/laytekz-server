# WP19 citation-picker

## Summary
⇧⌘E (Ctrl+Shift+E) opens the citation picker over the editor: search the
project's references by author, year, title words or key (every word must
match; case and accents are ignored, so "lamport 94" and "muller 2020" work),
Tab to cite several, pick a style (Parenthetical, Narrative, and the family's
other forms), add a prenote and a locator, Enter to insert or Shift+Enter for
the other main style. The command follows the document's package (WP15's
`GET …/cite-setup`): biblatex gives `\parencite`/`\textcite`, natbib
`\citep`/`\citet`, apacite `\cite`/`\citeA`, plain BibTeX `\cite`. With the
caret in a citation, the picker edits it (chips, style and notes prefilled;
"Remove citation"). ⇧⌘Space (Ctrl+Shift+Space) switches the citation at the
caret between narrative and parenthetical, rewriting only the command name.
The Cite and Zotero panels insert the document's parenthetical command
(an automatic change with its own switch). `\cite` completion now searches
several words with accents folded, the new command forms complete, and
`\cref{a,` completes the label after the comma with its kind.

## Marked hunks
`apps/web/src/editor/latexExtras.ts` (every hunk carries `Galley: V2 (WP19)`):
- `CITE_RE`: also matches apacite's `\cite<see>{` and the later groups of a plural citation (`\textcites{a}{b`).
- `KEY_COMMANDS`: adds `\citep* \citet* \Citep \Citet \citealt \citeyearpar \Citeauthor \parencite* \Parencite \Textcite \parencites \textcites \Autocite \citeA \citeNP`.
- `cachedBib` and `loadBib(projectId, branch, fresh = false)` are exported, for the picker (shows the cache, refetches with `fresh`).
- `foldText`, `surnames`, `citeRank(e, q, cited?)` (exported): multi-word AND, case and diacritic folding (TeX accents too), key prefix 5 > surname prefix 4 > year 3 (two digits match the year's end) > title-word prefix 2 > anywhere 1; keys cited in the file get +0.5. The completion query is no longer lower-cased by the caller.
- `LabelInfo` and `labelCache`: label entries keep the server's `kind`, `title`, `envTitle`.
- `refCompletionSource`: completes the label after the last comma (`\cref{a,|`), `validFor` stops at a comma; the detail is the kind ("Figure", "Section", a theorem's printed name) and the file when it is another one; `info` is the caption or heading. `KIND_TEXT`/`labelKindText` at the end of the file.

`apps/web/src/editor/citeInsert.ts`:
- `citationEdit(text, from, key, to = from, command = 'cite')`: the new citation's command (V1's `\cite` by default; callers are unchanged).

`apps/web/src/editor/__tests__/citeInsert.test.ts`: an appended describe block for the command parameter.

- **Hunk:**
  ```diff
  -  labels: (id: string, branch: string) => req<Array<{ label: string; file: string }>>(`/api/projects/${id}/labels?branch=${encodeURIComponent(branch)}`),
  +  // Galley: V2 (WP19) detail=1: kind, title and line for the completion detail (WP15)
  ```

## Deviations
- **File layout.** The plan names `citeCommands`, `refIndex` and `PickerShell` under `features/citations`; they are there (`citeCommands.ts`, `refIndex.ts`, `PickerShell.tsx`). The bib cache stays in `latexExtras.ts` (exported) rather than moving to `refIndex.ts`, because the V1 completion and hover tests mock it there; `refIndex.ts` holds the cite-setup cache.
- **Where the picker is drawn:** an `editor.overlay` slot item (`citations.picker`, `PickerHost`) that renders the lazily loaded `CitePicker` while `store.ts` says it is open. The picker is a `role="dialog" aria-modal` sheet with its own `.picker` class (not `.palette`), so ⌘K and page chords stay off while it is open.
- **Family when the server has not answered yet:** the open file's own preamble (`detectFamilyIn`), else plain BibTeX. The setting `citations.family` (Automatic / biblatex / natbib / apacite / plain `\cite`) overrides both. The picker refetches cite-setup on every open; page `docChanged`/`filesChanged` only mark the cached answer stale.
- **Online fallback:** "Search papers online for …" (and "Import from Zotero" when the project has no entries) closes the picker and opens the References / Zotero panel through `page.ui.showPanel('plugin:references', query)`, instead of searching and adding inside the picker. WP22 owns that panel's search and preview.
- **Edit mode** refuses plural citations (`\textcites{a}{b}`) with a toast: rebuilding them would lose groups. ⇧⌘Space still switches them (`\parencites` ⇄ `\textcites`).
- **The panels' command is an automatic change** (`citations.panels`, on by default, a palette toggle): under `aldine.settings.testDefaults='automatic-off'` it is off and the panels insert `\cite` as in V1, which keeps specs 05, 06 and 07 unchanged (the starter paper loads biblatex).
- **Spacing:** the picker adds one space before a citation typed straight after a letter or digit (`citations.spacing`). The plan's "Figure " → "Figure~" part belongs to WP26.
- **Notes in edit mode** are written back exactly as found unless the person changes the prenote or locator fields; then the locator is rewritten in the family's form (biblatex `12`, others `p.~12`).
- **Not built (later or other packages):** Visual mode's Mod+Enter on a cite chip opening edit mode (needs `visual/index.ts`, WP37's in wave 4); "Sync Zotero now" in the picker; toasts in the plugin panels naming the inserted command (WP22); the "More" menu is a row of style buttons instead.

## Privacy notes
No new data leaves the browser. The picker reads `GET /api/projects/:id/bib` (as `\cite` completion did) and `GET /api/projects/:id/cite-setup` (WP15), both the project's own files. The four switches and two choices are account-scope settings (synced with the account's preferences like every account setting).
