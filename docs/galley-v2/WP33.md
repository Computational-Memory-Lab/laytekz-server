# WP33 stats-core

## Summary
The pure core of feature 16 (statistics): the APA 7 house style and its
validator, number formatting on decimal strings, the catalogue of about 100
statistics with their LaTeX templates, the renderer (prose, math, table cell,
Greek by preamble) and the converter (R `htest` prints, `summary(lm)` lines,
SciPy result reprs, BayesFactor, APA-like text) plus "Reformat statistics in
this file". The server stores the per-project house style. Nothing is visible
to a user yet: WP38 (stats-editor) wires the core into the editor (triggers,
fields, picker, paste offer, settings rows).

## Deviations
- **Bayes factor triggers** are `\bayes10`, `\bayes01` and `\bayesplus`, not the report's `\bf10`, `\bf01`, `\bfplus`: TeX reads a control word as letters only, so `\bf10` is the real command `\bf` followed by `10`, which the acceptance "never shadows a real LaTeX command" forbids. Their keywords include "bf10", "bf01" and "bf+0" so the picker still finds them by those names.
- **Added entry** `\shapiro` (Shapiro–Wilk, bounded W), which the converter needs and the report lists only as a converter case.
- **Kind `PC`** (p in a table cell) is a kind of its own instead of a flag on `P`; `\pcell` uses it.
- **Template syntax:** a prefilled field is `⟦label:KIND=95⟧` (the report wrote `⟦95:LVL⟧`); the `P` field always writes its relation, so there is no `=` prefix on labels. The Kruskal–Wallis symbol and the credible-interval label are the template variables `⟨KW⟩` and `⟨CRI⟩`.
- **Not done in this package (left for later, see "For later packages"):** table recognisers for pingouin, JASP, jamovi and SPSS text; `summary(lm)` coefficient rows and `summary(aov)` rows.

## For later packages
**WP38 (stats-editor)** builds on these exports (all pure; no CodeMirror, React or store imports):

- `core/style.ts`: `StatsStyle`, `APA7`, `STATS_STYLE_SETTING` (`'stats.style'`, project scope; the stored value is `styleDiff(style)`, a partial object), `isStatsStyleDiff` (use it as the SettingDef's `validate`), `resolveStyle(stored)` (never throws), `styleDiff`, `isApa7` ("APA 7" vs "Custom" with "Reset to APA 7" = store `{}`), `STYLE_KEYS`.
- `core/format.ts`: `formatValue(kind, raw, style) → {text, value, rel?, warning?}`. `text` is what the field holds after leaving it (for `P` it includes the relation: `= .029`, `< .001`). A `warning` means the value was kept as typed: underline the field and show the warning. `passesThrough(raw)` (macros such as `\StudyOneP`, words).
- `core/catalogue.ts`: `CATALOGUE`, `GROUPS`, `entryById`, `entryByTrigger('\\pval')`, `triggersStartingWith('\\pv')`, `searchCatalogue('mann whitney')`. Entries carry `title`, `group`, `keywords`, `rule` (one line for the completion info) and `template`.
- `core/render.ts`: `render(entry, {context, style, greek, values, format, prune, sColumn, kinds})` → `{text, fields: [{label, kind, from, to, optional, warning?}]}`. Insert `text`, then open the fields at `from..to` (empty fields have `from === to`; draw the ghost placeholder from `label`). Re-render with `values` keyed by label when a field is left (or format the one field with `formatValue` and splice it), and with `prune: true` at finish to drop empty optional parts (`⟪…⟫`). `greekMode(style, {upgreek, unicodeMath})` picks the Greek mode from the preamble; `sample(entry)` gives the preview text ("$p = .028$"); `joinRendered(parts, context)`.
- `core/parse.ts`: `convertStatistics(text, {style, greek}) → {text, count, fields}` (empty `fields` are values the output lacked, such as the chi-square `N`: open them as fields); `looksLikeTestOutput(text)` (the paste offer's test); `recognise(text)` (blocks with offsets); `reformatStatistics(text, {style, greek}) → {text, count, changes}` (apply `changes` as one transaction for one undo step); `inlineMathSpans(text)`.

Contexts: insert in prose with `context: 'prose'`; inside `$…$`, `\(…\)`, `\[…\]` or a math environment (but not inside `\text{}`/`\mbox{}`) use `'math'`; in a tabular cell use `'cell'`, with `sColumn` in a siunitx `S` column.

Still to build (core side, small): table recognisers (pingouin/JASP/jamovi/SPSS by header names `T`, `dof`, `p-val`, `p-unc`, `Sig.`, `CI95%`, `cohen-d`, `np2`, `BF10`), `summary(lm)` coefficient rows and `summary(aov)` rows. Add them as further recognisers in `parse.ts` returning `Recognised` blocks; nothing else changes.
