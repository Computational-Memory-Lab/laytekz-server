# WP39 pet-engine

## Summary
The engine of the optional desk pet (feature 14). The server reads the
operator's image (`ALDINE_INSTANCE_PET`), refuses JPEG and animated images
with a reason, announces it through `GET /api/capabilities` (`pet`) to
signed-in callers only, and serves it at `GET /api/instance/pet/:variant?`
with `private` caching. On the web, five pure modules hold everything the
pet does: the asset client, the account-synced preferences with their
setting definitions, the behaviour state machine, the motions as Web
Animations keyframes, and the perch geometry. Nothing is visible to a user
yet: WP44 (pet-runtime) renders the pet with these modules.

## Requests

### R1: deploy (V2 location to be decided by the integrator): `libexec/sync-pet-asset.sh`
- **Anchor:** a new file; `deploy.sh` calls it after the server tree is synced
  (`"$HERE/libexec/sync-pet-asset.sh"`), and `config/app.env.template` gains
  `ALDINE_INSTANCE_PET=@ROOT@/assets/pet/pet.png`.
- **Hunk:**
  ```sh
  #!/usr/bin/env bash
  # Galley: V2 desk pet. Copies the operator's pet image to the server, outside
  # every source tree, tarball and backup. Does nothing when the image is absent.
  set -euo pipefail
  SRC="${PET_SOURCE:-$(cd "$(dirname "$0")/../.." && pwd)/private-assets/pet/pet-idle.png}"
  HOST="${DEPLOY_HOST:?set DEPLOY_HOST}"
  DEST_DIR="${PET_DEST_DIR:-galley-server/assets/pet}"
  if [ ! -f "$SRC" ]; then echo "sync-pet-asset: no pet image at $SRC; the desk pet stays hidden"; exit 0; fi
  ssh "$HOST" "umask 077 && mkdir -p '$DEST_DIR' && chmod 700 '$DEST_DIR'"
  rsync --chmod=F600 "$SRC" "$HOST:$DEST_DIR/pet.png"
  echo "sync-pet-asset: copied the pet image (mode 600, directory 700)"
  ```
- **Why:** the owner's pet reaches the app only as an operator file read at
  boot; this puts it where `app.env` points, with private modes.
- **Without it:** the operator copies the file by hand (plan §1.4); with no
  file the server logs one boot warning and the setting stays hidden.

## Deviations
1. **Discovery is `GET /api/capabilities`, not a meta tag**, as the plan
   decided (§1.1 row 14). The key is `pet: {v, w, h, s}`: `v` the image's
   version (12 hex digits), `w`/`h` its size (null for an SVG without one),
   `s` the silhouette's version or null. Signed-out callers on a server with
   accounts get no `pet` key; a server without accounts gives it to everyone
   (there is nobody to sign in).
2. **The route answers 404 before 401** when no image is configured, so an
   unconfigured server says nothing either way; with an image, signed-out
   callers get 401.
3. **Settings scope:** every `pet.*` setting is `account` scope (plan §1.1:
   "Settings follow the account"); "away until" is a plain device key,
   `aldine.pet.awayUntil` (epoch ms), outside the registry so it never syncs.
4. **GIF** is refused as an animated format (the analyst's list had APNG and
   animated WebP; a GIF pet would be either animated or palette-banded).

## Privacy notes
- The image is never in a repository, fixture, `public/` or installer; the
  e2e fixture is a grey ellipse generated by a script.
- `cache-control: private` always (`immutable` only for the current `?v`),
  `cross-origin-resource-policy: same-origin`, `nosniff`, a sandbox CSP, so a
  CDN never stores it and another site cannot embed it.
- The image path is logged at boot only in a refusal warning; it is never
  sent to a client.
- The web engine contacts nothing but the same-origin image URL; the
  preferences sync with the other account settings (WP02), and "away until"
  stays in this browser.

## Operator variables
| Name | Default | Effect |
|---|---|---|
| `ALDINE_INSTANCE_PET` | unset | Path to a still PNG, WebP or SVG (≤ 512 KB, transparent background). Set: signed-in people get a "Desk pet" section in settings. JPEG and animated images are refused with a boot warning. |
| `ALDINE_INSTANCE_PET_SILHOUETTE` | unset | Optional dark shape of the same figure (same rules, aspect ratio within 2%). Without it the app darkens the image for the fade-in, which looks the same. |

## For later packages
**WP44 pet-runtime** builds on these, all in `features/pet/engine/`:
- `features/pet/settings.ts`: `export { PET_SETTINGS as settings } from './engine/prefs';`
  (pure data; `visible()` hides every row unless the capability is present).
- Read preferences with `petPrefsFrom(getSetting)` and watch `PET_SETTING_IDS`
  with `subscribeSetting`. Away: `readAwayUntil(safeStorage, now)`,
  `sendAway(safeStorage, now)` (returns the time; toast text
  `awayMessage(until)`), `bringBack(safeStorage)`; listen to `storage`
  events on `AWAY_KEY` for other tabs.
- Image: `petAssetFrom(getCapabilities())`, `petImageUrl(asset)`, then
  `measurePet(asset, url)` once for the paw line (`PetShape`).
- Brain: keep one `BrainState` (`initialBrain(Date.now())`), call
  `step(state, input, ctx)` for each event and once more with `{type:'tick'}`
  at `wakeAt` (one setTimeout). Feed only local events: `keydown` and
  `pointer` from passive window listeners; `compileStart`/`compileEnd` from
  `compileRequested`/`compileFinished` (`own`, `trigger`; a `requestError` or
  stopped run flagged); `roster` from `page.peers()` on `rosterChanged`, with
  yourself and agents flagged; `comment` for a new comment id whose author is
  not you on `commentsChanged`; `visibility`, `focus`, `click`, `hover`.
  Never feed `docChanged` with `local: false`.
- Play `result.motion` with `motion(name, currentPose, {playful, reducedMotion, dir})`
  → `el.animate(spec.keyframes, spec.options)`, and keep `spec.to` as the
  current pose; `control: 'pause' | 'resume'` maps to `Animation.pause()` /
  `play()`. `wander: true` means: after `sinkOut`, place on the next
  available perch and play `riseIn`.
- Place with `place(perchRects, shape, current, prefs.perch, prefs.size, env)`
  from the `[data-perch]` spacers (null: render nothing), `availablePerches`
  for `ctx.perchCount`, `perchAt` for drops, `overlaps` to hide before paint.
  The clip box is `position: fixed` at `left/top/width/height` with
  `overflow: hidden`; the image box sits at `bodyTop` inside it.
- Image element: a background image on a div (cannot be dragged out),
  `transform-origin: 50% 100%`, `z-index: var(--z-pet)`, hidden under
  `forced-colors` and print.
