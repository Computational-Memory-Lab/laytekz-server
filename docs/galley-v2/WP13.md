# WP13 math-hover

## Summary
Hovering over math in the source (Source mode, and revealed formulas in
Visual mode) shows it drawn by KaTeX with the document's own macros, at the
document's font size, on a white "paper" sheet by default. Errors are text
("Can't draw this formula: …" with the error position underlined in the
source; "Can't draw \foo: not defined in the preamble…" for unknown commands).
A setting adds an Overleaf-style preview that follows the caret, and a
command (unbound by default) pins the preview at the caret; Escape closes
either. The feature never changes the document, so there is nothing to undo
and collaborators see nothing. `registerPreviewTier` is the contract for
WP21's exact PDF crop.

## Deviations
- **Setting ids** (account scope, section `math`, pure data in `settings.ts`): `mathPreview.hover` (true; the main switch: off installs nothing and KaTeX is not preloaded; `palette: true`), `mathPreview.caret` (false), `mathPreview.delay` (150 | 350 | 700, default 350: Short, Normal, Long), `mathPreview.size` (`small` | `medium` | `large`, default medium: 1.33, 1.75 or 2.25 CSS px per point), `mathPreview.background` (`paper` | `theme`, default paper), `mathPreview.pdf` (true, `visible: () => false` until WP21's layer exists). The report's device keys `aldine.mathPreview*` became registry settings, so the device mirror is `aldine.mathPreview.hover` etc. None is `automatic`: they show something and change nothing.
- **The hover preview takes no pointer events.** It never covers a click on the lines below, which keeps legacy specs and real clicking safe. The cost is that a hover preview cannot be scrolled: a wide formula shrinks down to 60%, and anything wider is clipped. The pinned preview takes pointer events and scrolls. The preview closes as soon as the pointer leaves the formula, even over lines it covers (CodeMirror would otherwise count the preview's area as part of the hover).
- **Macros are read when a preview draws**, from the file's own preamble or the root file's (`rootPreambleText()`) with what they `\input` (`withIncludes`), memoised on that text. `macroField` and the `refresh.ts` view registry are not used: the registry has no reference count, so a feature compartment that unregistered its view would cut Visual mode's redraw pokes. A root preamble that arrives while a preview is open counts at the next preview.
- **Shortcut:** `mathPreview.pin`, "Preview the formula at the cursor", scope `editor`, group Editor, default unbound (plan §1.1). The report's Mod+Shift+E belongs to Insert citation.
- **Where the PDF layer plugs in:** `index.ts` loads `./pdf/index.ts` through `import.meta.glob` (no match: KaTeX only), with an `ImportMeta.glob` declaration in `index.ts`, because the web tsconfig loads no `vite/client` types. If the integrator ever adds those types, delete that `declare global` block.
- **Not built from the report (outside the plan's acceptance):** the stacked preview of several formulas in one selection (a selection inside one formula previews on its own); a selection of plain prose does not preview; `\newcommand` in the document body is not read; the "changed since the last typeset" captions and the TeX error from the last typeset (these need WP21's compiled-text field).

## Privacy notes
No new requests. The previews read the root preamble and the files it `\input`s through the existing file API, exactly as Visual mode does. Nothing leaves the browser except the six preference values: they are account scope, so when the account syncs preferences (WP02) they are stored with the account on the server.

## For later packages
- **WP21 (PDF crop):** create `features/mathPreview/pdf/index.ts` exporting `activate(page: EditorPageCtx): void | (() => void)`. It is loaded automatically when it exists (`import.meta.glob`), and its cleanup runs when the page closes. Register the tier there:
  ```ts
  import { registerPreviewTier } from '../api';
  export function activate(page: EditorPageCtx) {
    return registerPreviewTier({ id: 'pdf', priority: 100, render: async ({ target, filePath, pxPerPt, paper, signal }) =>
      cropFor(target, filePath, pxPerPt, paper, signal) /* { tier: 'pdf', dom: canvas, caption: 'As typeset', title } | null */ });
  }
  ```
  KaTeX draws first; the first tier that returns a result replaces it in place (the height is held), `data-tier` becomes the result's `tier`, and null, a throw or a rejection keeps KaTeX. `signal` aborts when the preview closes. To show the `mathPreview.pdf` switch, ask the integrator to change its `visible: () => false` in `features/mathPreview/settings.ts` (frozen after wave 1); read it with `getSetting('mathPreview.pdf')`.
- **WP38 (statistics):** `UPRIGHT_ALIASES` in `editor/visual/katex.ts` draws `\upalpha`…`\upOmega` as the KaTeX Greek letter and `\symup`, `\symrm`, `\mathup` as `\mathrm`, `\symbf` as `\boldsymbol`, `\symit` as `\mathit`, in every KaTeX render. `documentClassOf(text)` and `documentFontSize(text)` are in `editor/visual/preamble.ts`.
- **Features 2 and 4 (math detection):** `hoverTarget`, `caretTarget`, `selectionTarget` and `katexInput` are exported from `features/mathPreview/api.ts`. `katexInput` turns a `Formula` into what KaTeX can draw (numbered displays starred, `multline` gathered, unknown displays aligned).
- **Escape:** the key chain entry `mathPreview.close` (priority 85) returns false when no preview is open, so lower entries still get the key.
