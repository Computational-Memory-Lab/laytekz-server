# WP18 table-tools

## Summary
Feature 4 is now visible. A table button sits in the editor header of every
`.tex` file (both modes): it opens a grid picker ("4 × 3" follows the
pointer, arrows and Enter work too) with options for the caption and label,
a header row, the rule style and the column alignment, and, when the cursor
is in a table, "Align columns" and a "Rows and columns" menu. A new table is
one undo step (with `\usepackage{booktabs}` when the preamble is in the same
file); in Source mode Tab walks its cells, then the caption, then the label,
and in Visual mode the first cell opens for typing and an empty caption shows
"Add a caption". ⇧⌥A aligns the table at the cursor (a second press says it
is already aligned), the palette has "Align all tables in this file" and
"Table: …" row and column operations, keep-aligned realigns a table that was
aligned before your edit when the cursor leaves it (its own undo step), and
Format document realigns tables through `afterFormat`. Every part has a
switch in Settings → Tables.

## Deviations
- **Placement of the float.** A float goes on its own lines after the current line, at that line's indentation (the snippet indents every line under it), not at "the line's indent plus `indentUnit`"; the rows inside are indented by the editor's indent unit.
- **Lines option.** The picker shows Booktabs, `\hline` and None; the stored value starts as "Automatic" (booktabs when the preamble loads it or is in this file, otherwise `\hline`) and becomes the explicit choice once one is clicked. Settings → Tables can set it back to Automatic.
- **Booktabs in another file.** When the preamble is elsewhere, the picker reads the main file once (cached 30 s) to see whether it loads booktabs. If someone picks Booktabs and it does not, the table goes in and a toast says `Booktabs rules need \usepackage{booktabs} in main.tex.` with an "Open main.tex" button; the line is not added to the other file automatically (the page has no API to edit a file other than the open one in one undo step).
- **Format document.** `afterFormat` realigns with the client aligner; the compiler's `align: false` flag (report §3.3) is not built, because `apps/compiler/format.js` is never edited in V2. latexindent therefore still aligns `&` as before, and "Format document aligns table columns" off only skips the client pass.
- **"Make a table from the selection"** (tab-separated text) is not built; a selection is never replaced.
- **Keep-aligned in Visual grid edits** (composing the realignment into a cell commit) is not built (WP14 left it too); keep-aligned acts on typing in the source.

## Privacy notes
- The picker reads the project's main file from this server (`GET /api/projects/:id/file`) to see whether its preamble loads booktabs. Nothing leaves the server; nothing is stored beyond a 30-second in-memory cache.
- The last grid size is kept in this browser (`localStorage['aldine.tables.lastSize']`); the picker options are device-scope settings (`aldine.tables.insert*`); keep-aligned, the format switch, padding and the width limit are account-scope settings.

## For later packages
- `openTablePicker(page)` (`features/tables/bus.ts`) opens the header button's picker, or inserts a 3 × 3 table when the button is hidden.
- `insertTable(view, options)` (`features/tables/actions.ts`) inserts a table as one undo step with userEvent `input.table`.
- Snippet fields: the tables feature puts `nextSnippetField`/`prevSnippetField` at Tab/Shift-Tab priority 90 and `clearSnippet` at Escape 95, so any CodeMirror `snippet()` in a `.tex` file gets Tab fields under the key chains (WP38's statistic fields can rely on them or add their own at the same priority).
